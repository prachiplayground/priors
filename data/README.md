# data

- `manifest.csv`: every source and its pipeline status (`found` → `fetched` → `extracted` → `reviewed` → `published`).
- `raw/`: fetched source texts for extraction. **Git-ignored and never published.**
- `transcripts/`: podcast transcripts for the staging dataset. **Git-ignored and never published.**

The first 30 rows are the pilot set, the vetted personalization reading list.
