# evals

Three eval suites, each published with its results:

| Suite | Measures | Target |
| --- | --- | --- |
| Extraction | Field-level accuracy against hand-labeled records | ≥ 90% on core fields before scaling |
| Retrieval | Relevance of matched precedents for a given product context | To be set after the pilot |
| Evidence, not decisions | LLM-judge rubric: does the assistant cite evidence and avoid prescribing decisions? | To be set after the pilot |
