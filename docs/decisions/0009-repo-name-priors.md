# 0009. Name the repository `priors`

- **Date:** 2026-11-11
- **Status:** Accepted

precedent; prd-sidecar; whetstone; trellis; cocreate; priors

## Decision and reasoning
Short and accurate: a prior is what you know before you decide, which signals that the tool informs judgment rather than replacing it. Repos can be renamed later with automatic redirects.
