# 0001. Widen scope to all big-tech PM case studies, organized into category buckets

- **Date:** 2026-11-11
- **Status:** Accepted

## Options considered
Personalization only (deep); all PM case studies (broad), organized into buckets

## Decision and reasoning
Category buckets enable cross-category comparisons and a broader product, while bucket-specific fields keep depth within each category.

## Revisit if
Per-bucket depth suffers at scale.
