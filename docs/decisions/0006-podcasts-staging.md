# 0006. Podcasts go to a separate staging dataset

- **Date:** 2026-11-11
- **Status:** Accepted

## Options considered
Exclude podcasts; mix them in directly; transcribe and analyze separately, then promote selected decisions

## Decision and reasoning
Podcasts are rich in reasoning but rarely report hard results, so their quality profile differs from papers and blogs. Transcripts stay private.

## Revisit if
Staging analysis shows podcast decisions are as reliable as written sources.
