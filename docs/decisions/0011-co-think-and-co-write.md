# 0011. Position priors as co-think and co-write, with a Think step before the PRD

- **Date:** 2026-11-11
- **Status:** Accepted

## Options considered
Co-write only (PRD drafting assistant); co-think and co-write, adding an explicit Think step before structuring the PRD

## Decision and reasoning
The most valuable moment is before drafting: framing the problem, seeing how comparable teams framed theirs, and surfacing tradeoffs. Generic AI PRD writers start at the document, so a Think step is also the clearest differentiator. The "product teams from across big tech in the room" framing is kept, with an explicit caveat that the room holds their published decisions, not the people, and that published accounts skew toward success. Tagline: "A room full of product precedent. You run the meeting." A non-affiliation statement was added so citing company names never implies partnership.

## Revisit if
Discovery interviews show PMs value the drafting help far more than the thinking help.
