# 0002. Design for an ever-expanding corpus

- **Date:** 2026-11-11
- **Status:** Accepted

## Options considered
One-time static dataset; continuously growing corpus

## Decision and reasoning
The product only improves if new precedents keep arriving. A living manifest, RSS intake, schema versioning and versioned releases make growth routine, and a review gate prevents dilution.

## Revisit if
Review load outgrows the time available.
